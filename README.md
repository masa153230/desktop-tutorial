# スイング研究室

iPhone の Safari で使うゴルフスイング研究アプリ。インストール不要、1ファイル (`index.html`) で動く。
「何か変えたら良くなった気がする」を、動画の計測と A/B 比較実験の数字で確かめるためのもの。

## できること
- **動画**: 撮影した動画 (ライブラリから選ぶ or その場で撮る) をコマ送り・スロー再生
  - 動画を読み込むと始動・トップ・インパクト・フィニッシュを自動で判定し、バックスイング/ダウンスイングの時間とテンポ比を計算
    - 前のコマとの差 (動きの量) の推移から、「バックスイング → トップで一瞬ほぼ止まる → 一番速いダウンスイング」の谷を探してトップとする
    - 始動はトップから遡って動きが静止レベルまで落ちる所、インパクトはトップ直後の山の上側の重心
    - 谷は前後との比で判定するので、撮影者の手ブレ・ズームや背景の人の動きにある程度強い
    - 実際のスイング動画2本 (室内練習場の手持ち撮影、テレビ映像の画面収録) で、手で見たコマと 0〜2 コマの差
    - トップは「手と体が止まるコマ」。クラブはしなりと慣性でその後 2〜3 コマ動き続けるので、クラブ基準より早めに出る
    - 高fps動画はトップとインパクト付近だけ 0.25 倍速で再生し直してコマ単位まで詰める
    - 始動→インパクトが長すぎる時はスロー動画とみなして倍率 (2/4/8×) を推定する
    - 外れたら手で上書きできる
  - 動きの量のグラフに各フェーズの位置を表示。タップでその位置へ移動
  - 各マークが ±1 コマずれた場合のテンポ比の幅も出す (30fps だとダウンスイングは 7〜8 コマしかなく、誤差がかなり大きい)
  - 1 コマの長さは再生中に表示されたコマの時刻差から実測する (`requestVideoFrameCallback`)
  - 線 (地面との角度)・角度 (3 点)・円 (頭の位置の基準) を動画の上に描ける
  - 2 本並べて比較。「インパクトを揃えて同時再生」でインパクトが同じ瞬間に来るように再生し、再生中もずれを自動で補正する (スロー倍率が違っても実時間で揃える)
- **実験**: 条件 A と B (例: いつものグリップ vs ストロング) を比較する
  - 比べる数字は「ボールの結果 (手入力)」か「スイングの計測 (動画から)」。後者は動画タブで保存するときに実験と条件を選ぶと、テンポや骨格推定の数字がそのまま入る
  - 打つ順番をアプリがランダムに決める (2 球ずつのブロックで AB/BA)。疲れ・慣れ・風の変化が差に混ざらないように
  - キャリーなどの指標 1 と、左右のブレ (または任意の数値) の指標 2 を記録
  - Welch の t 検定で平均の差と 95% 信頼区間、Brown–Forsythe 検定でばらつきの差
  - 「意味のある差」を検出するのにあと何球必要か (検出力 80%)
  - 打順の偏り・打つうちに数値が伸びる/落ちる傾向を警告。多重比較の注意も出す
  - 弾道測定器のメモなどをまとめて貼り付けて取り込める
- **体の動き (骨格推定)**: 同梱の MediaPipe Pose で、始動の少し前からフィニッシュまでの関節位置を推定する
  - 頭の最大移動・アドレス→インパクトの頭の左右/上下 (身長比 %)、体の軸の傾きの変化、肩・腰の回転 (正面撮影時の推定)、腰の横ずれ、トップの手の高さ
  - 動画の上に骨格と頭の通り道を重ねて表示する
  - 2D の画像からの推定なので、同じ場所・同じ向きで撮った動画どうしで比べる。同じ動画を何度測っても ±0.3% 程度ぶれる
  - GitHub Pages 版のみ (claude.ai のアーティファクト版では部品を読み込めない)
- **記録**: 保存したスイングのテンポ比をクラブ別に集計し、推移をグラフにする。実質 100fps 未満の動画はテンポの集計から外す
  - **自動判定の当たり具合**: 自動判定のあとに手で直したフェーズのずれを溜め、平均のずれ・±1/±2 コマ以内の割合を出す。手直しが溜まったら平均のずれで自動判定を補正できる
  - 「動画も保存する」にしておくと動画もこの端末のブラウザ (IndexedDB) に保存され、記録から A/B どちらの枠にも開き直せる。付けたフェーズ・線・メモ・スロー倍率も戻る
  - Safari はホーム画面に追加していないサイトのデータを 7 日使わないと消すことがあるので、ホーム画面に追加して使う
- **Claude のアドバイス**: 始動・トップ・インパクト・フィニッシュの静止画 (比較中なら A/B 2段) とテンポの数字を Claude に見せて、見えたこと・優先課題1つ・ドリル・実験タブで確かめる A/B 案をもらう
  - claude.ai のアーティファクト版ではアプリの中で直接聞ける (初回に Claude の利用と画像送信の許可を聞かれる)
  - GitHub Pages 版では同じ画像と質問文を作り、共有シートで Claude アプリに渡す
  - アドバイスは計測と一緒に保存され、記録タブで読み返せる
- **Claudeに見せる**: 計測と実験結果をテキストにしてコピー。Claude に貼って相談できる

データは端末のブラウザ (localStorage と IndexedDB) に保存される。
記録タブの「バックアップ / 復元」で、動画ごと ZIP (data.json + videos/) に書き出して、別の端末やブラウザに戻せる。

## iPhone で使う
1. このリポジトリの Settings → Pages で公開するブランチを選ぶ (このブランチをマージ後なら `main`)
2. Safari で公開 URL を開く
3. 共有ボタン → 「ホーム画面に追加」でアプリっぽく起動できる

## 撮影のコツ
- 正面 (飛球線と直角) か後方 (飛球線の延長上) から、三脚などで固定して撮る。手持ちだと線の角度が意味を持たない
- テンポを測るならスロー撮影 (120fps / 240fps)。その場合は動画タブの「撮影時のスロー倍率」を合わせる
  (iPhone のスロー動画はスロー再生の状態で渡されることが多い。始動→インパクトが 2 秒を超えたら倍率が合っていない可能性が高い)

## テスト
`tests/` に Playwright のテストがある。main への push と PR のたびに GitHub Actions で Chromium (Linux) と WebKit (macOS、iPhone の Safari と同じエンジン) の両方で動く。

```
cd tests && npm ci && npx playwright install chromium webkit && npx playwright test
```

テスト用の動画 (`tests/fixtures/`) は腕と棒が回るだけの合成スイング (`make_swing.py` で作成)。正解は 始動 0.80s / トップ 1.565s / インパクト 1.83s。
