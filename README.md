# スイング研究室

iPhone の Safari で使うゴルフスイング研究アプリ。インストール不要、1ファイル (`index.html`) で動く。
「何か変えたら良くなった気がする」を、動画の計測と A/B 比較実験の数字で確かめるためのもの。

## できること
- **動画**: 撮影した動画 (ライブラリから選ぶ or その場で撮る) をコマ送り・スロー再生
  - 始動・トップ・インパクト・フィニッシュを付けると、バックスイング/ダウンスイングの時間とテンポ比を計算
  - 各マークが ±1 コマずれた場合のテンポ比の幅も出す (30fps だとダウンスイングは 7〜8 コマしかなく、誤差がかなり大きい)
  - 1 コマの長さは再生中に表示されたコマの時刻差から実測する (`requestVideoFrameCallback`)
  - 線 (地面との角度)・角度 (3 点)・円 (頭の位置の基準) を動画の上に描ける
  - 2 本並べて比較。インパクトで揃える / 始動から同時再生 (スロー倍率が違っても実時間で揃える)
- **実験**: 条件 A と B (例: いつものグリップ vs ストロング) を比較する
  - 打つ順番をアプリがランダムに決める (2 球ずつのブロックで AB/BA)。疲れ・慣れ・風の変化が差に混ざらないように
  - キャリーなどの指標 1 と、左右のブレ (または任意の数値) の指標 2 を記録
  - Welch の t 検定で平均の差と 95% 信頼区間、Brown–Forsythe 検定でばらつきの差
  - 「意味のある差」を検出するのにあと何球必要か (検出力 80%)
  - 打順の偏り・打つうちに数値が伸びる/落ちる傾向を警告。多重比較の注意も出す
  - 弾道測定器のメモなどをまとめて貼り付けて取り込める
- **記録**: 保存したスイングのテンポ比をクラブ別に集計し、推移をグラフにする
- **Claudeに見せる**: 計測と実験結果をテキストにしてコピー。Claude に貼って相談できる

データは端末のブラウザ (localStorage) に保存される。動画そのものは保存しないので写真アプリに残しておくこと。
記録タブの「バックアップ / 復元」で全データを JSON でコピーできる。

## iPhone で使う
1. このリポジトリの Settings → Pages で公開するブランチを選ぶ (このブランチをマージ後なら `main`)
2. Safari で公開 URL を開く
3. 共有ボタン → 「ホーム画面に追加」でアプリっぽく起動できる

## 撮影のコツ
- 正面 (飛球線と直角) か後方 (飛球線の延長上) から、三脚などで固定して撮る。手持ちだと線の角度が意味を持たない
- テンポを測るならスロー撮影 (120fps / 240fps)。その場合は動画タブの「撮影時のスロー倍率」を合わせる
  (iPhone のスロー動画はスロー再生の状態で渡されることが多い。始動→インパクトが 2 秒を超えたら倍率が合っていない可能性が高い)
