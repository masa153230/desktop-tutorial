# よろず道場

英語・モンゴル語・チェス・麻雀をレッスン形式で学ぶ1ファイルの学習アプリ。

- 公開版（claude.ai アーティファクト）: https://claude.ai/artifact/FEDj4yYjMQMXkeoFqrrktb
- 進捗はアーティファクトの `db`（本人だけが読める `data/users/<id>/progress`）と、ブラウザの localStorage に保存。端末ごとの進捗は XP・レッスン・復習予定・間違いノートを合算してマージする。
- 画面はURLの `#home` `#course-…` `#lesson` `#chess` `#mahjong` `#mjreview` で切り替わるので、スマホの戻るボタンで1つ前の画面に戻る。

## 構成

| ファイル | 中身 |
| --- | --- |
| `src/content.js` | 教材（英語・モンゴル語の例文、チェスの局面、麻雀の手牌） |
| `src/mahjong.js` | アガリ判定・待ち計算・打牌候補・点数計算・牌のSVG |
| `src/app.js` | 画面とレッスン進行 |
| `src/play.js` | フリープレイの画面（チェス対局・麻雀の卓）。ビルド時に app.js の中へ入る |
| `src/board3d.js` | チェスの3D盤（Three.js r128：回転体の駒・影・木目の盤・駒の移動アニメ・駒はドラッグかタップで動かす、視点はボタンで切り替え）。2Dに切り替え可 |
| `src/mj3d.js` | 麻雀の3D卓（Three.js）：厚みのある牌、山と王牌のドラ表示、立てた手牌、河、副露、点数パネル、リーチ棒。流局・和了時は手牌を倒して公開 |
| `src/chessai.js` | チェスCPU（0x88盤の αβ探索＋静止探索）。ルール判定と棋譜は chess.js |
| `src/mjgame.js` | 麻雀の対局：向聴数、役・符・点数、4人の進行、CPUの打ち方（押し引き込み） |
| `src/head.html` | タイトルとスタイル |
| `build.js` | 上を1枚の `index.html` にまとめる |
| `tests/verify.js` | チェス問題の合法性・詰みの有無、待ち計算、点数計算の検証 |
| `tests/chess-engine.js` | チェスCPUの perft（標準5局面）、1手詰め、自己対局 |
| `tests/mj-game.js` | 役・符・点数の既知値、向聴数、CPU4人の東風戦40回で点棒が保存されるか |

```sh
node build.js                 # index.html を作る
cd tests && npm i && node verify.js && node chess-engine.js && node mj-game.js
```

## 中身

- 英語 30ユニット（場面・文法・語彙・やりがちなミス・発音の聞き分け）、モンゴル語 26ユニット（キリル文字・格・動詞の時制・否定・疑問・場面）。各ユニットに「ポイント」の解説。
- 忘却曲線（1・3・7・14・30・60日）で「今日の復習」を出す。英語は音声入力が使える環境で発話問題も出る。
- チェス 10ユニット（駒の動き〜2手詰め・終盤・戦術）、麻雀 11ユニット（牌〜鳴き・押し引き・符計算・役満）。何待ち・何切る・点数・符・安全牌はランダム生成のドリル。

## フリープレイ

- チェス：CPU 5段階（αβ探索・置換表・ヌルムーブ・LMR・定跡）。持ち時間・評価バー・ヒント・待った・オープニング名。終局後に全手を解析して精度・悪手・最善手・評価グラフを表示、PGN コピー。CPU は Web Worker で動く。
- 麻雀の卓：中央の点数表示のまわりに4人の河を各自の向きで並べ、卓を奥に傾けて立体的に表示。相手の手牌（伏せ）・副露・リーチ棒・発声（ポン！リーチ！）・打牌音つき。
- 麻雀：CPU3人と東風戦／半荘戦／1局。チー・ポン・明槓・暗槓・加槓、赤ドラ、槓ドラ、嶺上・槍槓・海底・河底・一発・ダブル立直・天和・地和、喰いタン・後付けあり、喰い替え禁止、ダブロン、途中流局（九種九牌・四風連打・四家立直・四槓散了・三家和）、流し満貫、ダブル役満、25000持ち30000返し・ウマ10-30。CPU は牌効率＋現物・筋・壁での押し引き、役の当てがあるときだけ鳴く。ヒント（向聴数・おすすめ打牌・鳴いたあとの向聴数・待ち・フリテン・役なし・安全牌）。

## 振り返りと解説

- 「なぜ？」ボタン：チェスの悪手（終局後の解析で疑問手・悪手・大悪手の手）、麻雀の推奨と違う打牌・危ない押し・放銃、対局中のヒントで Claude が解説する（アーティファクトの `sample` 機能）。エンジンが計算した事実（評価値の差・最善手と読み筋、受け入れ枚数・向聴数・現物の有無）だけをプロンプトに入れ、それ以外は推測しないように指示している。初回は許可を求められる。
- 麻雀の振り返り（`#mjreview`）：牌効率の一致率、受け入れを減らした打牌、リーチ者がいる時の押し、放銃の一覧（現物があったか）。対局中は「ここまでの振り返り」、終局後は「この対局を振り返る」から開く。
- 麻雀の途中保存：各局の開始時に点数・本場・供託・親・統計を保存し、ホームに戻っても再読み込みしても「続きから」でその局の頭から再開できる（局の途中の手牌までは保存しない）。
- 3D表示は描画が1フレーム45msを超える状態が続くと、影を切り解像度を下げて軽くする。

チェスの合法手判定は chess.js 0.10.3（cdnjs → jsDelivr の順に読み込み）。
