# キゲンメモ

買ってきた物のバーコードを読み取って、食品・日用品・化粧品の期限と在庫を管理する Web アプリ。
iPhone の Safari で使う想定。インストール不要で、ホーム画面に追加するとアプリとして動く。

## できること
- **バーコードの読み取り**: カメラをかざすだけで連続して読む (JAN / EAN-13・EAN-8・UPC)。カメラが使えない時は写真から読む、または手入力
  - 画面中央の帯を優先して読み、ZXing では同じ番号が 2 回続いたら確定する (誤読を減らすため)
  - チェック数字が合わない番号は捨てる
  - Android の Chrome では端末内蔵の BarcodeDetector を使う (速い)
- **商品情報の自動取得**: Open Food Facts / Open Beauty Facts / Open Products Facts を同時に引く
  - 食品: 商品名・容量・栄養成分 (100g あたり)・アレルゲン・原材料
  - 化粧品: 開封後の使用期限 (PAO、例: 12M) があれば、開封した日から自動で期限を計算
  - 見つからない物は手で入れた名前を覚え、次からは通信せずに出す。一度調べた番号は 30 日間は通信しない
  - 店内コード (2 で始まる番号) はその店だけの番号なので、検索しない
- **期限の管理**: 期限が近い順に「期限切れ / 3日以内 / 1週間以内 / 1か月以内 / それ以降 / 期限なし」で並べる
  - 期限 = 印字の期限 と 開封日 + 開封後の期限 の早い方
  - 消費期限切れは「食べない方が安全」、賞味期限切れは「品質の目安」と分けて表示する
  - 同じ商品の 2 回目以降は、前回の「買ってから期限までの日数」で期限を仮に入れる
  - 使った / 捨てた を記録し、月ごとの廃棄率を出す
  - ホーム画面から開くと、期限切れ + 3日以内の数をアイコンのバッジに出す (iOS 16.4 以降)
- **オフライン**: アプリ本体は Service Worker で保存するので、電波が無くても開ける (商品情報の検索だけできない)
- **バックアップ**: データはそのスマホの中 (localStorage) だけ。設定からバックアップの JSON を保存・復元できる

## できないこと
- バーコードに期限や成分は入っていないので、期限はパッケージの印字を見て入れる
- 日本の商品は Open Food Facts に無い物も多い。無い物は 1 回だけ手で入れる (アプリ内のリンクから Open Food Facts に登録もできる)
- 期限が近づいた時の通知は出せない (サーバーが要る)。開いた時とバッジで確認する
- 家族との共有はできない (データは端末ごと)

## 使い方
1. このリポジトリの Settings → Pages で公開されていれば、`https://<ユーザー名>.github.io/desktop-tutorial/kigen/` で開ける
2. iPhone は Safari の共有ボタン →「ホーム画面に追加」
3. 初回にカメラの許可を聞かれるので許可する

## ファイル
- `index.html`: アプリ本体 (1 ファイル)
- `sw.js`: オフライン用の Service Worker
- `manifest.webmanifest`, `icons/`: ホーム画面用
- `vendor/zxing-library-0.21.3.min.js`: バーコード解析 (ZXing、Apache-2.0。`vendor/ZXING-LICENSE`)

## テスト
`tests/kigen.spec.mjs` (Playwright)。商品データベースへの通信は偽の応答に差し替える。
テスト用のバーコード画像は `tools/make_kigen_fixture.py` で作る。

商品情報のデータ: Open Food Facts / Open Beauty Facts / Open Products Facts (ODbL)
